# Bot de promoções de placa de vídeo

Checa o Pelando a cada 15 minutos (GitHub Actions) e avisa no Telegram quando aparece promoção ou cupom de placa de vídeo.

- Filtros (modelos, preço máximo, buscas): edite `config.json`.
- Token e chat_id ficam nos *secrets* `TELEGRAM_TOKEN` e `TELEGRAM_CHAT_ID` do repositório.
- Rodar na mão: aba **Actions** → "Bot de placa de vídeo" → **Run workflow**.
